Send one approved WhatsApp template to everyone on a list or in a segment — now, or at a time you choose — and follow what happened. The API applies the same rules as the app: promotions only reach customers who opted in, nobody who replied STOP is messaged, and a campaign larger than your number's daily limit is spread over several days.

You need a plan with WhatsApp campaigns, a connected number, an approved template, and an API key with the whatsapp:campaigns scope.

Build the audience

Add people to a list by phone number. Numbers that aren't customers yet are created.

curl -X POST https://akilent.com/api/v1/lists/vip-customers/members \
  -H "Authorization: Bearer ak_live_xxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{ "phones": ["+260971234567", {"phone": "+260977000111", "name": "Bwalya Phiri"}],
        "contacts": ["c_8Hk2..."],
        "attested": true }'

attested: true records that these customers agreed to receive WhatsApp messages from your business — required for promotions. It never overrides a customer who opted out. Up to 1,000 people per request; the response lists any numbers that couldn't be added and why. DELETE the same path with the same body to take people off the list (they stay customers). GET /api/v1/lists/{id} shows how many on the list WhatsApp can reach.

To add one customer: POST /api/v1/contacts with just a phone (email is optional). Every contact comes back with phone, whatsapp (opted_in, updates, opted_out or none), tags and lists. PATCH a contact with {"whatsapp": "opted_in", "attested": true} or {"whatsapp": "opted_out"}.

Send or schedule a campaign

curl -X POST https://akilent.com/api/v1/whatsapp/campaigns \
  -H "Authorization: Bearer ak_live_xxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: weekend-offer-2026-10-24" \
  -d '{ "name": "Weekend offer",
        "list": "vip-customers",
        "template": "weekend_offer",
        "variables": { "name": "contact.first_name" },
        "fallbacks": { "name": "there" },
        "send_at": "2026-10-24T09:00:00",
        "timezone": "Africa/Lusaka" }'
Field
list / segmentExactly one: the list or segment id. A segment is checked again when the campaign sends.
templateThe template's name or numeric id. It must be approved and have no picture or file at the top.
variablesWhat goes in each blank: contact.first_name, contact.full_name, contact.phone, contact.<custom field>, account.company_name, or fixed text. Every blank needs one.
fallbacksOptional text per blank for customers with no value. Without one, those customers are skipped.
send_at, timezoneOptional. Leave out to send now. Recipients are chosen when it sends.
drafttrue saves it without sending; send it later from the app or with send_now.

Retrying with the same Idempotency-Key returns the same campaign and never sends twice. Problems the owner must fix (an empty list, a plan limit, an unapproved template) come back as 422 campaign_error with a readable message.

Follow it

GET /api/v1/whatsapp/campaigns/{id} returns status (draft, scheduled, sending, paused, sent, failed, cancelled), delivery counts (sent, delivered, read, failed, held, unconfirmed, pending) and not_sent_reasons (for example not_opted_in, opted_out, missing_value). GET /api/v1/whatsapp/campaigns lists them, newest first.

Pause, resume, cancel, send now

curl -X POST https://akilent.com/api/v1/whatsapp/campaigns/42/pause \
  -H "Authorization: Bearer ak_live_xxxxxxxxxxxxxxxxxxxxxxxx"

Actions: pause, resume, cancel and send_now (for a draft or scheduled campaign). An action that doesn't fit the campaign's state — pausing one that has finished — returns 409 invalid_state. Cancelling stops messages that haven't gone out yet; sent messages can't be called back.
