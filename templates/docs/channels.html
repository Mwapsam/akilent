Each channel offers a different amount through the API. This page lists what you can call for each one, and what you can only do in the app.

{% if "email" in enabled_channels %}

Email

Everything you send by email can be done through the API:

  • Send a message: POST /api/v1/messages, then check its status and events.
  • Templates: create, version and render reusable email templates.
  • Campaigns: send to many recipients at once.
  • SMTP relay: send over SMTP instead of HTTP.
  • Webhooks: get a signed callback when a message is sent, fails, is opened or is clicked.
{% endif %} {% if WHATSAPP_ENABLED %}

WhatsApp

The API has one WhatsApp endpoint:

  • WhatsApp one-time codes: POST /api/v1/whatsapp/verification-codes delivers a login or confirmation code, and GET on the same path returns its delivery status.

These are only in the app for now: connecting numbers, WhatsApp templates, WhatsApp campaigns, and replying to customers in the inbox. There's no endpoint to send a free-form WhatsApp message.

People who message you on WhatsApp become contacts. The Contacts API returns them with "source": "whatsapp".

{% endif %} {% if "instagram" in enabled_channels %}

Instagram

There's no Instagram endpoint yet. Connecting accounts, replying to direct messages in the inbox, and comment rules (automatic private replies and moderation) are only in the app.

People who message you on Instagram become contacts. The Contacts API returns them with "source": "instagram".

{% endif %} {% if WHATSAPP_ENABLED or "instagram" in enabled_channels %}

The Contacts API (/api/v1/contacts) is available on plans that include the email API. Contacts from every channel come back from it, each with the source it was created from.
