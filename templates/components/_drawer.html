{% comment %}Drawer chrome - a side sheet for a detail pane or filters. Rendered by {% drawer %} (apps/core/templatetags/ui.py). Same contract as the modal, so there is one API to learn: opens on window event "modal-open" with this drawer's id as detail; closes on the backdrop, the Close button, Esc (topmost dialog only) or $dispatch('modal-close'[, id]). Focus, Esc and background inertness come from window.akDialog (static/js/app.js), handed $root, never $el (see _modal.html). Right-hand sheet from sm up; full screen below, with the header pinned and the body scrolling, so a long pane never pushes its Close button off a phone screen. {% endcomment %}
