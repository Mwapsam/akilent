… {% include "components/_save_bar.html" %}
With scripts (static/js/app.js, html.ak-js) the plain button is hidden and this bar shows once a field changes, stuck to the bottom of the screen: Discard puts the fields back, Save submits. Leaving the page with changes asks first. Without scripts the plain button is all there is. ``label`` overrides the Save button's text.{% endcomment %}
