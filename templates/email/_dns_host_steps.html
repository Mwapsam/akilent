{% comment %}Step-by-step instructions for adding the records at each DNS host. Rendered inside the domain card's Alpine scope (tab). Every set of steps uses the Type shown on each record and the Host value, so none of them assumes TXT or a particular provider; the detected host only decides which tab opens first.{% endcomment %}
  1. Open your domain → DNS → Records → Add record.
  2. Set Type to the type shown on each record (TXT, CNAME or MX), and Name to its Host value.
  3. Paste the value into Content (TXT/CNAME) or Mail server (MX, with Priority 10).
  4. For CNAME records, set Proxy status to DNS only (grey cloud). Save, and repeat for each record.
  1. My Products → your domain → DNS → Add New Record.
  2. Choose the type shown on each record, and type its Host value in Name (@ means the domain itself).
  3. Paste the value. For MX, use Priority 10. Save, and repeat for each record.
  1. Domain List → Manage → Advanced DNS.
  2. TXT and CNAME: Add New Record, pick the type shown, put the Host value in Host and the value in Value.
  3. MX: under Mail Settings choose Custom MX, then add the record with Priority 10.
  4. Save each one with the green tick.
  1. Route 53 → Hosted zones → your zone → Create record.
  2. Type the Host value in Record name and pick the type shown.
  3. For MX, the value is one line: 10 feedback-smtp… (priority, a space, then the mail server). TXT values go in quotes.
  1. Open your domain's DNS settings → Custom records → Add record.
  2. Type the Host value in Host name and pick the type shown.
  3. Paste the value. For MX, use priority 10. Save, and repeat for each record.
  1. Networking → Domains → your domain.
  2. Pick the tab for the type shown, type the Host value in Hostname, and paste the value.
  3. For MX, use priority 10. Create the record, and repeat for each one.
  1. DNS zones → your zone → + Record set.
  2. Type the Host value in Name and pick the type shown.
  3. Paste the value. For MX, use preference 10. Save, and repeat for each record.
  1. Domains → your domain → DNS / Nameservers → Manage DNS records.
  2. Pick the type shown, type the Host value in Name, and paste the value.
  3. For MX, use priority 10. Add the record, and repeat for each one.
  1. Open the DNS or zone editor at the company that hosts your domain's DNS.
  2. Add each record above with the Type shown (TXT, CNAME or MX).
  3. In the name field, type the Host value. Only if your DNS host asks for the complete name, use the Full name instead.
  4. For MX, set priority 10. CNAME records must not be proxied or "flattened". Leave TTL at the default.
  5. Click Check DNS — if anything is off, the record will say exactly what we found.
