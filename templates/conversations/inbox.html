{% comment %} Live refresh, driven by HTMX rather than a bespoke fetch loop. The trigger filter skips a poll when the tab is hidden (no work in a background tab) and when focus is inside the list - re-writing the DOM under a keyboard user would throw their focus away every 8 seconds. The server answers 204 when the rendered list is byte-identical to the digest we send back in ?h=, and HTMX swaps nothing on a 204. after-request stores the new digest so the next poll can be compared against it. {% endcomment %} {% comment %}sr-only status region: announces a brief "Inbox updated" when the poll changes the list, without reading out the entire list to screen reader users.{% endcomment %} {% comment %}Search, within the view and channel: name, phone, email or anything said (views._inbox_context).
