{% comment %} For developers: what the public API does today, led by WhatsApp when that channel is live. The code sample is tabs (landing.js: WAI-ARIA tabs); without JavaScript every sample shows, one under another. Every request and payload is the real shape: - POST /api/v1/whatsapp/campaigns (apps/api/whatsapp_campaign_views.py), approved templates only; - POST /api/v1/events (apps/api/event_views.py): a business event such as order.paid, which starts workflows with that trigger and is passed on to webhooks as event.received; - the webhook body is {"event", "data"}, signed in X-Akilent-Signature (apps/email/webhooks.py); - POST /api/v1/messages for email. The API has no "send one WhatsApp message" call and no message.received webhook, so neither is shown. {% endcomment %}
